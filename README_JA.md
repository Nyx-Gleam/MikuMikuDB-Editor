## 概要

MikuMikuDB エディターは、Project Diva カスタム楽曲パック向けの設定ファイル `mod_pv_db.txt` を、コードを書かずに直感的なインターフェースで生成できるツールです。パックのメタ情報、楽曲情報、難易度、クレジット、歌詞、効果音、出演者、複数のオーディオバリアントなどを一貫して管理できます。

* **インターフェース:** 英語・スペイン語・日本語。設定画面からいつでも切り替え可能（言語ごとの別ビルドは廃止）。
* **配布形式:** 単一の実行ファイル（Windows 10/11 対応）。Python や依存関係は不要。
* **出力:** 暗号化された `.pdpack` プロジェクトファイルと、最終的な UTF-8 エンコードの `mod_pv_db.txt`。

## 2.0 の新機能

今回のバージョンは単なる機能追加ではなく、アプリケーション全体の作り直しです。

* **UI 基盤の刷新:** Tkinter から **PySide6（Qt）** へ移行 — ネイティブなダークテーマ、ネイティブなドラッグ＆ドロップ、手動のスケーリング処理が不要になった HiDPI 対応。
* **即時オーディオプレビュー:** 従来はプレビューのたびに一時 WAV ファイルを書き出しサブプロセスで再生していましたが、新版では `QMediaPlayer` を直接使用するため、一時ファイルなしで再生・シークが即座に行えます。
* **本当のトライリンガル対応:** 英語・スペイン語・日本語が単一ビルドに統合され、設定画面からいつでも切り替えられます。
* **楽曲エディターに新しい2つのタブ:**
  * **Lyrics（歌詞）** — `.txt`、`.srt`、`.vtt`、`.ass`、`.ssa`、`.lrc` からのインポートに対応し、日本語・英語の行を同期できます。
  * **SFX（効果音）** — 楽曲ごとに Button、Slide、Chain Slide、Slider Touch、Chance の効果音を設定できます。
* **BPM 計算機** — タップテンポ（外れ値の除外と平均化つき）に加え、オーディオファイルからの自動検出（任意）にも対応。
* **Song Info の新フィールド:** イラストレーター（Illustrator）。
* **新しい任意フィールド:** 英語版タイトルの読み（Song Name Reading EN）。
* **インストール済み MOD ブラウザ** — mods フォルダをスキャンし、名前・ID・アーティストで全 MOD を横断検索。インストール済み MOD と現在のプロジェクト間で楽曲をインポート／エクスポートできます。バニラ楽曲は集計から除外されるため、正確な曲数が表示されます。
* **メディアファイル検証ツール** — 各楽曲の音声・動画・バリアントファイルが実際にディスク上に存在するか確認します。
* **不足フォルダの作成** — `sound/song`、`movie`、`script`、`2d` を生成し、`config.toml` が無ければデフォルト内容で作成します。
* **PV ID のオンライン検証** — 確定する前に、その PV ID が既に使用済みか予約済みかを確認できます。
* 診断用の独立ツールとして **`.pdpack` Decryptor Tool** を別途同梱。
* 今回の作り直しの過程で、長年気づかれていなかった不具合も多数修正されました。例：二度と開けなくなる暗号化フォーマットの不具合、自動保存のファイル名衝突、起動時の深刻なフリーズ、決め打ちだった MOD フォルダのパス、難易度のレベル範囲の誤りなど。

## 主な機能

1. **パック情報**
   * **Pack Name**（ローマ字）と任意の**日本語名**を入力。
2. **楽曲ライブラリ**
   * テーブル表示で複数楽曲を管理（PV ID、原題、英題）。
   * 専用ボタンで楽曲の追加・編集・削除。
3. **楽曲エディター**（7 タブ構成）
   * **Basic Information（基本情報）:** PV ID、原題・英題、ひらがな読み、ローマ字、BPM（タップ／自動検出計算機つき）、日付(YYYYMMDD)、サビ開始・長さ。
   * **Difficulties（難易度）:** Easy/Normal/Hard/Extreme/Extra Extreme の有効化と、各難易度の有効範囲内で `PV_LV_XX_X` コードを設定。
   * **Performers（出演者）:** 初音ミク、鏡音リン・レン、巡音ルカ、KAITO、MEIKO、弱音ハク、亞北ネル、咲音メイコ、重音テトから最大6名を選択。
   * **Song Info:** 編曲者、作詞者、作曲者／アーティスト、マニピュレーター、ギタープレイヤー、イラストレーター、PV 編集者の任意項目（オリジナル & 英語）。
   * **Lyrics（歌詞）:** 日本語・英語の歌詞を入力またはインポートし、行の同期が可能。
   * **Audio Variants（オーディオバリアント）:** 別バージョン（デュエット、ミックスなど）ごとに名称、アーティスト、サフィックス、出演者リストを設定。必要箇所ではひらがな読みが必須。
   * **SFX:** Button、Slide、Chain Slide、Slider Touch、Chance の効果音を設定。
4. **自動保存 & 手動保存**
   * 5 分ごとに `.pdpack` を自動保存（最大 60 ファイル）。
   * **Save Configuration** / **Load Configuration** による手動保存・読み込み。旧形式は自動的に移行されます。
5. **MOD と PV ID**
   * インストール済み MOD とその楽曲を閲覧し、全 MOD を横断検索。MOD と現在のプロジェクト間で楽曲を移動。
   * オンラインの使用済み／予約済みデータベースと照合して PV ID を検証。
6. **最終出力**
   * **Generate File** ボタンで、Project Diva パックにそのまま使える UTF-8 の `mod_pv_db.txt` を生成。
   * **Import mod_pv_db.txt** でいつでも同じファイルを再読み込みして編集を続行可能。

## 動作環境

* **OS:** Windows 10 または 11（64bit 推奨）
* **単体実行ファイル版:** Python やライブラリのインストールは不要。実行ファイルを起動するだけ。
* **ソースコードから実行する場合:** Python 3.12 以上に加え、`PySide6`、`cryptography`、`requests` が必要。任意: `pykakasi`（ひらがな自動生成）、`toml`（`config.toml` の読み込み）、`numpy` + `madmom`（BPM 自動検出）。

## インストール方法

### 簡単インストール（GitHub）

1. [GitHub Releases](https://github.com/Nyx-Gleam/MikuMikuDB-Editor/releases) ページにアクセス。
2. 最新の **`MikuMikuDB Editor.exe`** をダウンロード。
3. ダウンロードした `.exe` をダブルクリックで実行。
   * “発行元を確認できません” 警告が出た場合は、ファイルを右クリック → **プロパティ** → 「全般」タブの下部で **ブロックの解除** にチェック → **適用** → 再度実行。

### 代替インストール方法（GameBanana）

1. 本ツールの [GameBanana ページ](https://gamebanana.com/tools/19907) にアクセス。
2. 最新版の **`Editor.exe`** をダウンロード。
3. ダウンロード完了後、`Editor.exe` をダブルクリックで起動 — インストール不要。
   * Windows のセキュリティ警告が表示された場合：ファイルを右クリック → **プロパティ** → 「全般」タブの下部で **ブロックの解除** にチェック → **適用** → **OK**。

## 基本的な使い方

1. アプリを起動し、必要であれば **Settings（設定）** からインターフェース言語を選択。
2. **Pack Name** と任意の**日本語名**を入力。
3. **楽曲を追加:**
   * **Add Song** で楽曲エディターを開く。
   * **Basic Information** を入力（BPM が分からない場合は BPM 計算機を使用）。
   * **Difficulties** タブで難易度と有効なレベルコードを設定。
   * **Performers** タブで出演者を選択。
   * **Song Info** と **Lyrics**（任意）を入力。
   * 必要に応じて **Audio Variants** と **SFX** を設定。
   * **Accept** で楽曲リストに登録。
4. 曲を選択して **Edit** / **Delete** で管理。
5. 必要に応じて **インストール済み MOD** を閲覧し、他のパックの楽曲を確認・再利用。
6. **Validate Media Files** で不足ファイルがないか確認し、**Create Missing Folders** で MOD のフォルダ構成を作成。
7. 必要に応じて **Save Configuration** で `.pdpack` を保存。
8. **Generate File** をクリックして `mod_pv_db.txt` を出力。

---

## 設定 & 自動保存

* **Auto-Save:** 5 分ごとに `Autosaves/` フォルダへ暗号化 `.pdpack` を保存（最大 60 個）。
* **Save Configuration / Load Configuration:** 任意のタイミングで手動保存・読み込み。旧形式の `.pdpack` は自動的に移行されます。
* **Load Autosave:** 自動保存ファイル一覧から復元。

---

## `mod_pv_db.txt` の出力

1. **Pack Name** が設定され、楽曲が 1 曲以上あることを確認。
2. **Generate File** をクリック。
3. ファイル名（デフォルト: `mod_pv_db.txt`）と保存先を指定して保存。
4. パック全体の定義を含む UTF-8 形式の `mod_pv_db.txt` が生成される。
5. **Import mod_pv_db.txt** で同じファイルをいつでも再読み込みして編集を続けられます。

## プロジェクト構成

```text
MikuMikuDB-Editor/
├── main.py                  # エントリーポイント
├── core/                    # アプリのロジック（暗号化、PV ID、再生、pv_db フォーマットなど）
├── ui/
│   ├── dialogs/              # 楽曲エディター、BPM 計算機、MOD ブラウザなど
│   ├── widgets/               # 再生／シークバーなど共有ウィジェット
│   └── main_window.py
├── localization/             # 言語データの読み込み（data/lang.json）
├── data/                     # 設定、バニラ楽曲カタログ、言語テキスト
├── pv_ids/                   # 使用済み／予約済み／未使用 PV ID のキャッシュ
├── standalone_scripts/        # 独立した .pdpack Decryptor Tool など
├── docs/guide.md              # アプリ内ユーザーガイド
├── tests/                     # 回帰テストスイート
└── Autosaves/                 # 自動保存された .pdpack ファイル
```
